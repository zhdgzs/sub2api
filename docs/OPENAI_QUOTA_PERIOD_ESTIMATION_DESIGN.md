# OpenAI 账号周期用量历史与预计总费用

> 状态：已实施。历史预测额度与页面 7d 预计总费用使用同一后端计算结果。

## 支持范围与触发

- 历史支持 OpenAI OAuth Plus、Team、Pro 主额度周窗口，不支持 Free、5h 或 Spark 独立额度。
- 普通和流式 API 用量成功入库后触发本地更新，按账号节流 30 秒；组装页面用量窗口时也更新。
- API 入口只读取已有上游比例缓存，不增加上游请求。节流期间的用量在下一次触发时重新汇总。
- 没有实际请求时不创建历史记录；历史写入失败只记录日志，不改变请求结果、扣费或页面统计。

## 统一预计总费用

```text
预计总费用 = 7d 窗口账号费用 × 100 ÷ 使用比例
```

- 金额与比例必须为有限正数，计算结果也必须为有限正数；否则当前页面不显示估算。
- 无 5% 门槛，1%、5% 等有效正比例均可计算；不平滑、不取最大值。
- 费用采用账号口径 `Cost`，包含账号倍率，不使用用户扣费 `UserCost` 或标准费用。
- 有效未来上游重置时间减 7 天作为窗口起点；无有效重置时间时使用采样时间减 7 天。
- 页面返回的 `seven_day.estimated_total_cost` 由后端统一计算，前端直接展示，两位小数；没有字段或为空时不在前端重新计算。
- 页面统计完成后将同一估算对象交给历史服务保存，不再为历史预测重复查询窗口金额。
- API 后台入口复用相同的进度解析、窗口起点和估算方法。过期窗口合成的 0% 不产生估算，也不用于切分历史。
- 同一次采样的页面与历史估算相同；不同采样时刻可能因新增用量或上游比例变化而不同。

## 实际用量历史

每周期保存实际使用金额、Token 量（输入、输出、缓存创建、缓存读取之和）、请求数和使用比例。

- 首次使用有效重置时间减 7 天作为历史起点，否则沿用首次快照时间减 7 天。
- 新上游快照比例比此前降低超过 2 个百分点时，以该快照时间开始新历史周期；恰好降低 2 个百分点不切换。
- 自然重置时，以此前已知的到期时间开始新周期。只变化 5h 不切换周记录。
- 切换只补充旧记录结束时间，保留其最后保存的实际用量及最近有效估算；新周期有使用才建档。
- 历史金额、Token 和请求数按历史起点独立汇总；7d 页面窗口及预测窗口不随历史切分改变。
- 因此提前重置后，实际用量柱与预测额度柱可能采用不同起点，不能用历史 `used_usd` 重算预测额度。
- 原始比例快照时间用于重置判断；重复或更旧的比例快照不能重复切换。

## 快照存储与兼容

保留原 `openai_quota_periods` 表及实际用量字段，通过迁移 `243_openai_quota_period_estimates.sql` 增加：

| 字段 | 含义 |
| --- | --- |
| `estimated_total_cost` | 后端统一计算的预计总费用 |
| `estimate_window_started_at` | 对应 7d 费用统计起点 |
| `estimate_window_cost` | 计算采用的窗口账号费用 |
| `estimate_used_percent` | 计算采用的使用比例 |
| `estimated_at` | 该有效估算的采样时间 |

金额和比例使用不限制小数位数的 NUMERIC，避免保存时按固定精度舍入改变前端结果。

- 五个快照字段一起更新；无有效估算时保留最近一次有效快照及其采样时间，不伪造 0。
- 历史接口以可选 `estimate` 对象返回 `total_cost`、`window_started_at`、`window_cost`、`used_percent` 和 `sampled_at`；没有完整快照时省略。
- 已结束记录不重新估算；历史查询仅读取保存值，不查询用量明细或上游。
- 当前历史状态保存在 `accounts.extra.openai_quota_period`；记录最近采样时间，拒绝较早发起、较晚完成的更新覆盖新结果。
- 旧比例快照不得覆盖新估算；重复比例快照允许累计本地新用量。
- 原迁移文件保持不变。旧 `predicted_quota_usd` 采用不同口径，保留原列和数据但不读取、不更新、不迁移到新快照。
- 升级时自动新增字段，无额外开关。旧历史没有可信快照时只绘制实际用量，当前周期在下一次有效触发后保存新快照。

## 展示与访问权限

- 账号管理和用户侧订阅账号列表保留已有 7d 预计总费用，不新增重复的预测额度行或列表字段。
- 两个页面复用额度历史弹窗。用户侧接口仅允许读取当前用户有效订阅分组内的支持账号。
- 每个周期以两根并排柱展示预测额度（预计总费用，绿色）和实际使用金额（橙色），共用美元刻度，不堆叠。
- 没有估算时预测柱为 null，仅显示实际用量，提示暂无预计总费用快照；不使用旧口径值替代。
- 提示详情显示实际使用比例、Token、请求数，以及预测窗口、窗口账号费用、预测采样比例与时间。
- 页面注明预测窗口可能与实际用量周期不同，历史保存最近有效采样。
- 默认每页最近 20 个周期，按时间从早到晚绘图；保留起止时间、分页、加载、错误重试及账号切换隔离。

## 验证重点

- 1%、5%、正常比例、零费用、零比例、非有限输入和溢出结果遵循统一规则。
- 页面与历史复用相同金额和窗口；历史失败不影响页面，API 更新不增加上游请求。
- 提前重置后历史实际金额与完整窗口费用不同，预测仍与页面采用相同口径。
- 过期窗口、重复比例快照、旧比例快照和乱序采样不覆盖正确结果或错误切分。
- 已结束历史直接读取保存值，旧历史缺少估算时不补算、不伪造零值。
- 管理端与用户侧均能展示预测及实际用量，用户侧访问边界保持有效。
